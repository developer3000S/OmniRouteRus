# Справочник провайдеров

> **Автоматически сгенерировано** из `src/shared/constants/providers.ts` — не редактируйте вручную.
> Перегенерируйте с помощью: `npm run gen:provider-reference`
> **Последний раз сгенерировано:** 2026-05-17

Всего провайдеров: **177**. См. разбивку по категориям ниже.

## Категории

- **Бесплатный** — бесплатный тарифный план с API-ключом (настраивается через панель управления)
- **OAuth** — поток входа обрабатывается OmniRoute, API-ключ не нужен
- **Веб-куки** — оборачивает веб-приложение провайдера через аутентификацию по куки
- **API-ключ** — платный провайдер, настраивается через API-ключ (возможны бесплатные кредиты)
- **Локальный** — работает на машине пользователя (Ollama, LM Studio, vLLM и т.д.)
- **Поиск** — провайдеры веб-поиска
- **Аудио** — провайдеры только для аудио (TTS/STT)
- **Прокси апстрима** — провайдеры, которые проксируют запросы к другим провайдерам
- **Облачный агент** — долгоживущие кодирующие агенты (Codex Cloud, Devin, Jules)
- **Системный** — внутренние провайдеры OmniRoute (loopback и т.д.)

Дополнительные теги: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

Используйте панель управления по адресу `/dashboard/providers`, чтобы включить, настроить и протестировать каждый провайдер.
