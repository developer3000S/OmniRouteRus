> Автоматическое управление цепочками моделей с адаптивным скоррингом + авто-маршрутизация без конфигурации

## Авто-маршрутизация без конфигурации (`auto/` префикс)

> **НОВОЕ:** Создание комбинаций не требуется. Используйте префикс `auto/` напрямую в любом клиенте.

### Быстрые примеры

| Идентификатор модели | Вариант | Поведение                                                                 |
| ------------------- | ------- | ------------------------------------------------------------------------ |
| `auto`              | default | Все подключенные провайдеры, стратегия LKGP, сбалансированные веса       |
| `auto/coding`       | coding  | Веса, ориентированные на качество, подходят для генерации кода             |
| `auto/fast`         | fast    | Выбор с низкой задержкой                                                 |
| `auto/cheap`        | cheap   | Оптимизация по стоимости (сначала самый дешевый)                          |
| `auto/offline`      | offline | Предпочтение провайдерам с наибольшим доступным квотом                   |
| `auto/smart`        | smart   | Ориентировано на качество + повышенный уровень исследования (10%) для лучшего обнаружения моделей |
| `auto/lkgp`         | lkgp    | Явная LKGP (такая же, как `auto` по умолчанию)                           |

**Как использовать:**

```bash
# Любая IDE или CLI-инструмент, поддерживающий формат OpenAI
Базовый URL: http://localhost:20128/v1
API Ключ:  <ваш-ключ-конечной-точки>

# В вашем коде/конфигурации установите модель:
model: "auto"                 # сбалансированный вариант по умолчанию
model: "auto/coding"          # лучший для задач по кодированию
model: "auto/fast"            # самый быстрый доступный
model: "auto/cheap"           # самый дешевый за токен
```

**Что происходит:**

1. OmniRoute обнаруживает префикс `auto/` в `src/sse/handlers/chat.ts`
2. Запрашивает все **активные подключения провайдеров** из базы данных
3. Фильтрует те, у которых есть действительные учетные данные (API-ключ или OAuth-токен)
4. Определяет модель для каждого подключения (`connection.defaultModel` или первую модель провайдера)
5. Создает **виртуальную комбинацию** в памяти (не сохраняется в БД)
6. Маршрутизирует с использованием профиля весов выбранного варианта + стратегии LKGP

**Ключевые свойства:**

- ✅ **Всегда включено:** Нет переключателя, нет создания комбинаций, нет необходимости в конфигурации
- ✅ **Динамическое:** Автоматически отражает текущие подключенные провайдеры
- ✅ **Сессионная привязка:** LKGP обеспечивает приоритет последнего успешного провайдера
- ✅ **Поддержка нескольких аккаунтов:** Каждое подключение провайдера становится отдельным кандидатом
- ✅ **Нет записей в БД:** Виртуальная комбинация существует только для запроса, нулевая нагрузка на запись

**Внутри:**

```txt
Запрос: { model: "auto/coding" }
   ↓
src/sse/handlers/chat.ts обнаруживает префикс
   ↓
createVirtualAutoCombo('coding') → пул кандидатов из активных подключений
   ↓
handleComboChat (та же движок, что и сохраненные комбинации)
   ↓
Авто-скорринг выбирает лучший провайдер/модель для каждого запроса
```

## Как это работает (Сохраненные Авто-Комбо)

Движок Авто-Комбо динамически выбирает лучшего провайдера/модель для каждого запроса, используя **6-факторную функцию оценки**:

| Фактор     | Вес    | Описание                                      |
| :--------- | :----- | :---------------------------------------------- |
| Квота      | 0.20   | Оставшийся объем [0..1]                        |
| Здоровье   | 0.25   | Автоматический выключатель: ЗАКРЫТ=1.0, ПОЛОВИНА=0.5, ОТКРЫТ=0.0 |
| CostInv    | 0.20   | Обратная стоимость (дешевле = выше оценка)    |
| LatencyInv | 0.15   | Обратная задержка p95 (быстрее = выше)         |
| TaskFit    | 0.10   | Оценка соответствия модели × типу задачи     |
| Устойчивость| 0.10   | Низкая вариативность задержек/ошибок           |

## Наборы режимов

| Набор                   | Фокус        | Ключевой вес       |
| :---------------------- | :----------- | :--------------- |
| 🚀 **Быстрая доставка** | Скорость     | latencyInv: 0.35 |
| 💰 **Экономия**        | Экономия     | costInv: 0.40    |
| 🎯 **Качество сначала** | Лучшая модель | taskFit: 0.40    |
| 📡 **Оффлайн-режим**    | Доступность  | quota: 0.40      |

## Самоисцеление

- **Временное исключение**: Оценка < 0.2 → исключено на 5 минут (прогрессивный откат, максимум 30 минут)
- **Осведомленность автоматического выключателя**: ОТКРЫТ → автоматическое исключение; ПОЛОВИНА_ОТКРЫТ → запросы для проверки
- **Режим инцидента**: >50% ОТКРЫТ → отключение исследования, максимизация устойчивости
- **Восстановление после охлаждения**: После исключения, первый запрос является "пробным" с уменьшенным тайм-аутом

## Исследование бандита

5% запросов (настраивается) направляются на случайных провайдеров для исследования. Отключено в режиме инцидента.

## API

```bash
# Создать авто-комбо
curl -X POST http://localhost:20128/api/combos/auto \
  -H "Content-Type: application/json" \
  -d '{"id":"my-auto","name":"Auto Coder","candidatePool":["anthropic","google","openai"],"modePack":"ship-fast"}'

# Список авто-комбо
curl http://localhost:20128/api/combos/auto
```

## Соответствие задаче

30+ моделей оценены по 6 типам задач (`coding`, `review`, `planning`, `analysis`, `debugging`, `documentation`). Поддерживает шаблоны с подстановочными знаками (например, `*-coder` → высокая оценка кодирования).
