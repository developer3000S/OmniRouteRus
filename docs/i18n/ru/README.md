# 🎯 Комбо — Флагман

</div>

> **Комбо** — это цепочка моделей, по которой OmniRoute автоматически переключается. Квота исчерпана, поставщик не отвечает или стоимость возрастает — комбо бесшумно переключается на следующую модель. **Это то, что делает OmniRoute непобедимым.** 🛡️

### ⚡ Нулевая конфигурация — просто используйте `auto`

Нет комбо для создания. Установите модель на `auto` (или вариант) и OmniRoute создаст виртуальное комбо из ваших подключенных поставщиков, оценивая их в реальном времени:

| Идентификатор модели | Что оптимизирует                                                                               |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| `auto`               | 🎯 Сбалансированный по умолчанию (LKGP — придерживается вашего последнего хорошего поставщика) |
| `auto/coding`        | 🧑‍💻 Веса качества для генерации кода                                                            |
| `auto/fast`          | ⚡ Наименьшая задержка сначала                                                                 |
| `auto/cheap`         | 💰 Самый дешевый за токен сначала                                                              |
| `auto/offline`       | 🔋 Наибольший запас квоты / ограничений скорости сначала                                       |
| `auto/smart`         | 🔭 Качество сначала + 10% исследования для обнаружения лучших моделей                          |

##

### 🔀 Или создайте свое — 14 стратегий маршрутизации

| Цель                                          | Стратегия / комбо                                      |
| --------------------------------------------- | ------------------------------------------------------ |
| 🥇 Использовать подписку до оплаты            | `priority` / `fill-first`                              |
| ⚖️ Распределить нагрузку между аккаунтами     | `round-robin` · `weighted` · `p2c` · `least-used`      |
| 💸 Всегда самая дешевая подходящая модель     | `cost-optimized` · `auto/cheap`                        |
| 🧠 Передача длинного контекста между моделями | `context-relay` · `context-optimized`                  |
| 🎲 Случайная / приватная маршрутизация        | `random` · `strict-random`                             |
| 🤖 Просто сделайте это умным                  | `auto` (оценка по 9 факторам) · `lkgp` · `reset-aware` |

<sub>Движок Auto-Combo оценивает каждый кандидат по **9 факторам** (здоровье, квота, стоимость, задержка, процент успешных запросов, свежесть…) — см. [`docs/routing/AUTO-COMBO.md`](docs/routing/AUTO-COMBO.md).</sub>

### 🧱 Надежность встроена (3 независимых уровня)

| Уровень                           | Область             | Что делает                                                                                     |
| --------------------------------- | ------------------- | ---------------------------------------------------------------------------------------------- |
| 🔌 **Автоматический выключатель** | весь поставщик      | Останавливает избиение поставщика, который не работает вверху; автоматически восстанавливается |
| 💤 **Охлаждение соединения**      | один аккаунт / ключ | Пропускает ограниченный ключ, пока другие ключи продолжают обслуживание                        |
| 🎯 **Блокировка модели**          | поставщик + модель  | Карантин только одной модели с ограниченной квотой, а не всего соединения                      |

```
Комбо: "всегда включен"                         Стратегия: priority
  1. cc/claude-opus-4-7   ← подписка (используйте полностью)
  2. cx/gpt-5.5           ← вторая подписка
  3. glm/glm-5.1          ← дешевый резерв ($0.5/1M)
  4. kr/claude-sonnet-4.5 ← БЕСПЛАТНО, неограниченно (никогда не падает)
Результат: 4 уровня резервного копирования = нулевые простои
```

# 🗜️ Экономия 15–95% токенов — Автоматически

</div>

> **Зачем использовать много токенов, когда мало токенов делают трюк?** Каждый запрос проходит через конвейер сжатия OmniRoute **прозрачно** — без изменений клиента. Он объединяет идеи из [RTK](https://github.com/rtk-ai/rtk) и [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 51K+).

| Режим                            | Экономия   | Лучше всего для                            |
| -------------------------------- | ---------- | ------------------------------------------ |
| 🪶 **Легкий**                    | ~15%       | Всегда включенный безопасный по умолчанию  |
| 🪨 **Стандартный (Caveman)**     | ~30%       | Ежедневный кодинг                          |
| ⚡ **Агрессивный**               | ~50%       | Длительные сеансы с тяжелыми инструментами |
| 🔥 **Ультра**                    | ~75%       | Максимальная экономия                      |
| 🧰 **RTK**                       | 60–90%     | Выходы оболочки/теста/сборки/git           |
| 🔗 **Сложенный (RTK → Caveman)** | **78–95%** | Смешанные запросы + логи инструментов      |

**Реальный пример — стандартный режим:**

> **До (69 токенов):** _"Причина, по которой ваш компонент React перерисовывается, вероятно, заключается в том, что вы создаете новую ссылку на объект на каждом цикле рендеринга. Когда вы передаете встроенный объект как проп, React видит его как новый объект каждый раз, что вызывает перерисовку. Я бы рекомендовал использовать useMemo для мемоизации объекта."_
>
> **После (19 токенов):** _"Новая ссылка на объект при каждом рендеринге. Встроенный объект проп = новая ссылка = перерисовка. Оберните в useMemo."_
>
> **То же самое ответ. 72% меньше токенов. Нулевая потеря точности.** ✅

<br/>

### 📖 Как это работает — конвейер, архитектура и математика экономии</b></summary>

```
Клиент (10,000 токенов) ──▶ OmniRoute Сжатие (7 опций) ──▶ Поставщик (~1,080 токенов, до 95% экономии)
```

Комбо по умолчанию сложенное: `RTK → Caveman`. Когда оба действуют на одном и том же инструменте/контексте, экономия складывается:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Блоки кода, URL-адреса, JSON и структурированные данные **всегда защищены** движком сохранения. Автоматическое сжатие по порогу токенов или назначение конвейера сжатия на комбо маршрутизации.

| Переменная окружения | По умолчанию   | Назначение                           |
| -------------------- | -------------- | ------------------------------------ |
| `PORT`               | `20128`        | Порт API + панели управления         |
| `REQUIRE_API_KEY`    | `false`        | Требуется API-ключ для всех запросов |
| `DATA_DIR`           | `~/.omniroute` | Хранение базы данных и конфигурации  |

**Вас будут взимать плату за OmniRoute?** Нет — это бесплатное, открытое программное обеспечение на вашей машине. Вы платите только платным провайдерам напрямую. У OmniRoute нет системы выставления счетов.
**Настоящие ли бесплатные провайдеры неограниченными?** Да — Kiro, Qoder, Pollinations, LongCat, Cloudflare. Нет подвохов.
**Будет ли сжатие ухудшать качество?** Нет — оно сжимает только **ввод**; код, URL, JSON всегда защищены.
**Работает ли это, где заблокирован ИИ?** Да — 3-уровневый прокси + рынок 1proxy обеспечивают доступ ко всем 177 провайдерам.

## 🛠️ Технологический стек

</div>

- **Среда выполнения**: Node.js 20.20.2+, 22.22.2+, или 24.x LTS (рекомендуется 24 LTS)
- **Язык**: TypeScript 5.9 — **100% TypeScript** в `src/` и `open-sse/` (ноль `any` в основных модулях с версии v2.0)
- **Фреймворк**: Next.js 16 + React 19 + Tailwind CSS 4
- **База данных**: better-sqlite3 (SQLite) + LowDB (JSON легаси) — состояние домена, логи прокси, аудит MCP, решения маршрутизации, память, навыки
- **Схемы**: Zod (валидация ввода/вывода инструментов MCP, контракты API)
- **Протоколы**: MCP (stdio/HTTP) + A2A v0.3 (JSON-RPC 2.0 + SSE)
- **Потоковая передача**: Server-Sent Events (SSE) + мост WebSocket (`/v1/ws`)
- **Аутентификация**: OAuth 2.0 (PKCE) + JWT + API Keys + MCP Scoped Authorization
- **Тестирование**: Node.js test runner + Vitest (**4,690+ тестовых случаев** в 517 файлах — юнит, интеграция, E2E, безопасность, экосистема)
- **Платформы**: Desktop (Electron), Android (Termux), PWA (любой браузер)
- **CI/CD**: GitHub Actions (автоматическая публикация npm + Docker Hub при релизе)
- **Веб-сайт**: [omniroute.online](https://omniroute.online)
- **Пакет**: [npmjs.com/package/omniroute](https://www.npmjs.com/package/omniroute)
- **Docker**: [hub.docker.com/r/diegosouzapw/omniroute](https://hub.docker.com/r/diegosouzapw/omniroute)
- **Устойчивость**: Circuit breaker, экспоненциальное затухание, предотвращение herd, TLS spoofing, авто-комбо самоисцеление
